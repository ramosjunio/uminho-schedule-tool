Automatically scrapes class timetables from Universidade do Minho and publishes an updated .ics calendar feed every week with automatic naming and accurate Portugal timezone alignment.

📅 How to add to Google Calendar

  1. Open Google Calendar on your desktop.
  2. In the sidebar next to Other calendars, click + → From URL.
  3. Paste your calendar URL above and click Add calendar.
  4. The calendar will automatically name itself and sync classes periodically.
🍴 Want to set this up for your own course? Click here
  1. Fork the repository on GitHub to your account.
  2. Edit config.yml: change course_name, year, and optionally customize the calendar_name (this will be the name of your calendar in Google Calendar).
  3. Go to the Actions tab in your fork and click "I understand my workflows, go ahead and enable them".
  4. Under Actions → select Update Schedule → click Run workflow to build the calendar for the first time.
  5. Go to Settings → Pages → set Source to Deploy from a branch and select gh-pages.
  6. Your own custom calendar and webpage will be live automatically at your GitHub Pages URL!
